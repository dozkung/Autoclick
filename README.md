# AutoClicker (Windows)

Auto clicker ที่ตั้งจุดคลิกได้หลายจุด แต่ละจุดมีประเภทคลิกและเวลารอเป็นของตัวเอง โปรแกรมจะคลิกไล่ตามลำดับ 1 → 2 → 3 → … แล้ววนกลับไปจุดแรก

## ติดตั้ง

ต้องมี Python 3.10 ขึ้นไป `requirements.txt` จะติดตั้ง `pynput` (คุมเมาส์และปุ่มลัด) และ `Pillow` (วาดหมุดขอบเนียน)

```bat
python -m pip install -r requirements.txt
python main.py
```

ถ้าต้องการสร้างไฟล์ `.exe` ไฟล์เดียว ให้รัน `build.bat` จะได้ไฟล์ `dist\AutoClicker.exe` ที่เปิดแล้วไม่มีหน้าต่าง console

## วิธีใช้

1. เลือกประเภทคลิก เวลารอ และจำนวนครั้งที่แถว **ค่าเริ่มต้นจุดใหม่**
2. เอาเมาส์ไปชี้ตำแหน่งที่ต้องการคลิก แล้วกด **F8** (ค่าเริ่มต้น) ทำซ้ำได้ตามจำนวนจุดที่ต้องการ หรือจะกดปุ่ม **เพิ่มเอง** แล้วกรอกพิกัดก็ได้
3. ถ้าต้องการแก้จุดไหน ให้ดับเบิลคลิกแถวนั้น ลบด้วยปุ่ม Delete หรือใช้ปุ่ม ▲/▼ เพื่อสลับลำดับ
4. เลือกรูปแบบการวน: ไม่จำกัด / จำนวนรอบ / จำกัดเวลา (นาที) และจะตั้งค่าสุ่มเพี้ยนพิกัดหรือเวลาด้วยก็ได้ ช่อง **รอ hover (ms)** คือเวลารอหลังย้ายเมาส์ก่อนคลิกทุกครั้ง (ดูข้อควรรู้)
5. กด **F6** (ค่าเริ่มต้น) หรือปุ่ม ▶ เพื่อเริ่ม แล้วกดอีกครั้งเพื่อหยุด ระหว่างนับถอยหลัง 3 วินาที ให้คลิกเข้าไปที่หน้าต่างเกม
6. ปุ่ม **บันทึก…** / **เปิด…** ใช้เก็บและโหลดโปรไฟล์ (`.json`)

ช่องเวลา (รอ, เว้น, กดค้าง) เลือกหน่วยได้ว่าเป็น **ms / วินาที / นาที** และใส่ทศนิยมได้ เช่น `1.5` วินาที หรือ `0.5` นาที ในตารางจะแสดงเป็นแบบอ่านง่าย เช่น `500 ms`, `1.5 วิ`, `1 นาที 30 วิ` ตั้งเวลาได้สูงสุด 24 ชม. (กันพิมพ์ผิดหน่วยแล้วโปรแกรมรอนานเป็นปี) ส่วนไฟล์โปรไฟล์ยังเก็บเป็น ms เหมือนเดิม จึงเปิดไฟล์เก่าได้ตามปกติ

ประเภทคลิกมี คลิกซ้าย, คลิกขวา, ดับเบิลคลิก และกดค้าง ประเภทกดค้างจะกดปุ่มซ้ายค้างไว้ตามเวลาในช่อง "กดค้างนาน" แล้วค่อยปล่อย

### คลิกหลายครั้งที่จุดเดียว

แต่ละจุดตั้งได้ว่าจะคลิกกี่ครั้ง (**จำนวน** 1–1000) และเว้นระหว่างแต่ละครั้งนานเท่าไร (**เว้น** 10 ms–1 นาที ค่าเริ่มต้น 100 ms) เช่นตั้งจำนวน 3 เว้น 100 จะคลิก 3 ครั้งห่างกันครั้งละ 0.1 วินาที แล้วค่อยรอตามช่อง "รอ" ก่อนไปจุดถัดไป

- ใช้ได้กับทุกประเภท เช่นกดค้าง × 3 = กดค้างแล้วปล่อย 3 ครั้ง ส่วนดับเบิลคลิก × 3 = ดับเบิลคลิก 3 ครั้ง
- ถ้าตั้งสุ่มเพี้ยนไว้ พิกัดจะสุ่มใหม่ทุกคลิก และเวลาเว้นก็สุ่มเพี้ยนด้วย
- กดหยุดระหว่างที่ยังคลิกไม่ครบชุดได้ทันที
- ระหว่างรัน แถบสถานะจะบอกครั้งที่ เช่น `รอบ 2 · จุด #1 (2/3)`
- ไฟล์โปรไฟล์เก่าที่ยังไม่มีค่านี้เปิดได้ปกติ ทุกจุดจะเป็นจำนวน 1

### นับถอยหลัง และหยุดเมื่อสลับหน้าต่าง

ตั้งค่าได้ที่แถว **ตอนเริ่ม:**

- **นับถอยหลัง (วิ)** 0–30 ค่าเริ่มต้น 3: กดเริ่มแล้วหมุดจะหายทันที แถบสถานะขึ้น `เริ่มใน 3…` `2…` `1…` ระหว่างนี้ให้คลิกไปที่หน้าต่างเกม ถ้ากด F6 หรือเอาเมาส์ชนมุมระหว่างนับ จะยกเลิกโดยไม่มีคลิกเลย
- **หยุดเมื่อสลับหน้าต่าง** (เปิดอยู่เป็นค่าเริ่มต้น): หน้าต่างที่อยู่ข้างหน้าตอนนับถอยหลังจบจะถือเป็น "หน้าต่างเกม"
  - ถ้าสลับไปหน้าต่างอื่น (เช่น Alt+Tab ไปดูเว็บ) โปรแกรมจะ **หยุดชั่วคราว ไม่คลิก** แถบสถานะขึ้น `หยุดชั่วคราว: หน้าต่างเกมไม่ได้อยู่ข้างหน้า`
  - พอกลับมาที่หน้าต่างเกม จะรอครึ่งวินาทีแล้วทำต่อจากจุดเดิม
  - ระหว่างหยุดชั่วคราว F6 และการเอาเมาส์ชนมุมยังหยุดได้ตามปกติ ส่วนโหมดจำกัดเวลา เวลาจะยังเดินต่อ
  - ถ้าตอนนับถอยหลังจบ หน้าต่างข้างหน้ายังเป็นหน้าต่าง AutoClicker เอง จะไม่เริ่ม และขึ้น `สลับไปหน้าต่างเกมก่อนนับถอยหลังจบ`
  - ถ้าปิดหน้าต่างเกมไประหว่างทำงาน จะหยุดเลย และขึ้น `หน้าต่างเป้าหมายถูกปิด`
  - ปิด checkbox นี้ได้ถ้าต้องการให้คลิกต่อไม่ว่าหน้าต่างไหนจะอยู่ข้างหน้า
- ทั้งสองค่าบันทึกอยู่ในไฟล์โปรไฟล์ ไฟล์เก่าที่ยังไม่มีค่านี้จะได้ค่าเริ่มต้น (3 วินาที และเปิด)

### กดปุ่มคีย์บอร์ด

นอกจากคลิก ยังตั้งให้กดปุ่มคีย์บอร์ดแทรกในลำดับได้ เช่น คลิก → กด E → คลิก

1. กด **"เพิ่มปุ่มคีย์บอร์ด…"** (เริ่มที่ปุ่ม E) หรือแก้จุดเดิมแล้วเปลี่ยนประเภทเป็น "กดปุ่ม"
2. กด **"เลือกปุ่ม…"** แล้วกดปุ่มที่ต้องการ (ใช้ Ctrl/Alt/Shift ร่วมได้ เช่น Ctrl+E, Esc = ยกเลิก)
3. "กดค้างนาน" คือเวลาที่กดปุ่มค้างไว้ ค่าเริ่มต้น 50 ms (เกมบางเกมต้องเห็นปุ่มลงอย่างน้อย 1 เฟรม ถ้ากดไม่ติดลองเพิ่มเป็น 100)

- step กดปุ่มไม่มีพิกัด จึงไม่มีหมุดบนจอ ในตารางช่อง X จะแสดงชื่อปุ่มแทน
- ปุ่มถูกส่งไปที่หน้าต่างที่อยู่ข้างหน้า ควรเปิด "หยุดเมื่อสลับหน้าต่าง" ไว้ ไม่งั้นถ้าสลับหน้าต่าง ปุ่มจะไปโผล่ในแอปอื่น
- ตั้งปุ่มให้ตรงกับปุ่มลัดของโปรแกรมไม่ได้ (เช่น F6) ไม่งั้นโปรแกรมจะกดปุ่มหยุดตัวเอง
- ถ้าเกมรันแบบ Administrator ตัว AutoClicker ต้องรันแบบ Administrator ด้วย ไม่งั้นจะหยุดพร้อมข้อความ "ส่งปุ่มคีย์บอร์ดไม่สำเร็จ"

### หมุดบนจอ

ทุกจุดจะมีหมุดวงกลมพร้อมเลขลำดับแสดงอยู่บนจอ **ศูนย์กลางหมุดคือจุดที่จะคลิกจริง**

- สีบอกประเภทคลิก: น้ำเงิน = ซ้าย, ส้ม = ขวา, ม่วง = ดับเบิล, แดง = กดค้าง
- ถ้าจุดนั้นคลิกหลายครั้ง จะมีตัวเล็ก `×3` อยู่ใต้เลขลำดับ
- หมุดขยายตามการตั้งค่า scaling ของ Windows (เช่นที่ 150% หมุดจะใหญ่ขึ้น 1.5 เท่า)
- ขอบหมุดเนียน (anti-aliased) โดยใช้ Pillow ถ้าไม่ได้ติดตั้ง Pillow หรือ Windows ไม่รองรับ โปรแกรมจะใช้หมุดแบบธรรมดาที่ขอบเป็นขั้นบันไดแทน และขึ้นแจ้งที่แถบสถานะว่า "หมุดแบบเรียบไม่พร้อม ใช้แบบธรรมดา" ซึ่งยังใช้งานได้ครบทุกอย่าง

- **ลาก** หมุดเพื่อย้ายจุด ถ้าปล่อยในมุม kill switch หรือนอกจอ หมุดจะดีดกลับที่เดิม
- **คลิก** หมุดเพื่อเลือกแถวนั้นในตาราง ส่วน **ดับเบิลคลิก** หมุดจะเปิดหน้าต่างแก้ไข
- ปิด/เปิดหมุดได้ที่ checkbox "แสดงหมุด" หรือกด F7 (ค่าเริ่มต้น)
- ระหว่างรัน หมุดจะซ่อนเองเพื่อไม่ให้ clicker คลิกโดนหมุด แล้วจะกลับมาเมื่อหยุด

## ปุ่มลัด

ปุ่มลัดใช้ได้แม้หน้าต่างโปรแกรมจะไม่ได้ focus อยู่

| ค่าเริ่มต้น | ทำอะไร |
|---|---|
| **F6** | เริ่ม / หยุด |
| **F8** | เพิ่มจุดที่ตำแหน่งเมาส์ตอนนี้ (กดระหว่างรันไม่ได้) |
| **F7** | แสดง / ซ่อนหมุดบนจอ |
| เอาเมาส์ชน **มุมซ้ายบนสุดของจอ** | หยุดฉุกเฉิน (kill switch ปิดไม่ได้ และเปลี่ยนไม่ได้) |

### ตั้งปุ่มลัดเอง

กดปุ่ม **ปุ่มลัด…** ที่แถบล่าง แล้วกดปุ่มในแถวที่ต้องการเปลี่ยน จากนั้นกดปุ่มที่จะใช้แทน (กด Esc เพื่อยกเลิก) เสร็จแล้วกด **บันทึก**

- ใช้ได้ทั้งคีย์เดี่ยว และคอมโบที่มี Ctrl/Alt/Shift เช่น `Ctrl+Shift+1` (ต้องกด Ctrl/Alt/Shift ค้างไว้ก่อน แล้วค่อยกดคีย์หลัก)
- ใช้ Ctrl/Alt/Shift เดี่ยวๆ, Esc หรือปุ่ม Windows เป็นปุ่มลัดไม่ได้ และสองหน้าที่ใช้ปุ่มเดียวกันไม่ได้
- ปุ่มลัดอิงตำแหน่งปุ่มบนคีย์บอร์ด จะสลับภาษาไทย/อังกฤษก็ใช้ได้เหมือนเดิม
- กดค้างไว้ก็ทำงานแค่ครั้งเดียว
- ระหว่างที่หน้าต่างตั้งปุ่มลัดเปิดอยู่ ปุ่มลัดทั้งหมดจะใช้ไม่ได้ชั่วคราว
- ค่าที่ตั้งเก็บไว้ที่ `%APPDATA%\AutoClicker\settings.json` เป็นค่าของเครื่อง ไม่ได้อยู่ในไฟล์โปรไฟล์ ถ้าไฟล์นี้เสีย โปรแกรมจะกลับไปใช้ค่าเริ่มต้นและขึ้นเตือนที่แถบสถานะ
- ค่าเริ่มต้นของแสดง/ซ่อนหมุดคือ F7 ไม่ใช่ F9 เพราะ F9 ชนกับ Developer Console ของ Roblox

ถ้ามีหลายจอ "มุมซ้ายบนสุด" หมายถึงมุมของพื้นที่รวมทุกจอ ไม่ใช่มุมของจอหลัก เช่นถ้ามีจอเสริมอยู่ทางซ้าย ต้องเอาเมาส์ไปชนมุมซ้ายบนของจอเสริมนั้น และจะตั้งจุดคลิกไว้ในระยะ 3px จากมุมนี้ไม่ได้

## ข้อควรรู้

- ถ้าแอปเป้าหมายรันแบบ Administrator ต้องรัน AutoClicker แบบ admin ด้วย เพราะ Windows (UIPI) จะทิ้ง input ที่มาจากโปรเซสสิทธิ์ต่ำกว่าแบบเงียบๆ
- เกมที่อ่าน raw input หรือมี anti-cheat ระดับ kernel อาจไม่รับคลิกจำลอง หรืออาจตรวจจับได้
- **เกมที่คลิกโดนแค่จุดแรก จุดอื่นคลิกไม่โดน** (เช่น Roblox): เกมพวกนี้รู้ตำแหน่งเมาส์จากการขยับทีละเฟรม โปรแกรมจึงขยับเมาส์ 1px แล้วกลับที่เดิมทุกครั้งก่อนคลิก แล้วรอตามช่อง **รอ hover (ms)** (ค่าเริ่มต้น 50 อยู่ในแถวสุ่มเพี้ยน) ถ้ายังคลิกพลาด ให้เพิ่มเป็น 100–200 โดยเฉพาะตอนที่เกมเฟรมเรตต่ำ แต่ถ้าเป็นแอปทั่วไปที่ไม่มีปัญหานี้ ลดเหลือ 0–20 เพื่อให้คลิกเร็วขึ้น
- Windows Defender อาจเตือนว่าไฟล์ exe เป็นอันตราย (false positive) เพราะโปรแกรมคุมเมาส์และดักคีย์บอร์ด
